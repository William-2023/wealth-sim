# 复利投资与财富积累模拟器

一个单文件、离线可用的定投测算工具。拖动滑块即时看到资产增长曲线，支持每日 / 每月 / 每年三种定投节奏，并把通胀单独建模。

**在线使用**：添加到手机主屏幕后可完全离线运行。

---

## 功能

- 三种定投节奏可同时叠加：每日、每月、每年
- 名义收益率与通胀率分开输入，自动换算实际收益率
- 期末同时给出实际购买力与名义金额
- 原生 SVG 绘图，不依赖任何外部库或网络请求
- 深色模式、安全区适配、Service Worker 离线缓存

## 计算口径

这几条决定了算出来的数字，值得写清楚。

### 1. 按月复利，月利率取有效值

```
月利率 = (1 + 年化收益率)^(1/12) − 1
```

**不是** `年化 / 12`。后者会让 12 个月复合后的实际增长高于标注值（7% 会变成 7.23%），与"年化收益率"这个标签自相矛盾。取 12 次方根可使 `(1 + 月利率)^12` 严格等于 `(1 + 年化收益率)`。

### 2. 投入于每期期初入账（期初年金 / annuity due）

月投入在每月月初、年投入在每年年初入账，比期末入账多计一期利息，因此乘以 `(1 + 该期利率)`。这更贴近"发薪即买入"的真实节奏。

### 3. 日投按月汇总，不单独按日计息

```
月投入 = 每月定投 + 每日定投 × 365 / 12
```

实际操作中没有人为了几美元每天下单，都是攒满一个月一次性买入，所以这不是近似妥协，而是正确建模。

### 4. 年投入独立计算，不除以 12

年初一次性投入 $12,000 与每月初投入 $1,000 并不等价——前者的钱平均在市场里多待半年。7% / 25 年下，前者约 $812,000，后者约 $787,000，相差 3.1%。因为月利率取的是 12 次方根，年度现金流恰好落在月份网格的整数倍上，两组现金流共用同一利率、各自算完直接相加，可加性精确成立。

### 5. 实际收益率用费雪关系

```
实际收益率 = (1 + 名义收益率) / (1 + 通胀率) − 1
```

**不是** 简单相减。名义 10%、通胀 3% 时，正确结果是 6.80% 而非 7%，25 年下差额超过六万美元。

### 6. 定投金额假设随通胀同步上调

即以今日购买力衡量，每期投入的实际金额保持不变。这与工资增长、以及 IRA / 401(k) 额度本身按通胀指数化的事实一致。

### 完整公式

设 `r` 为实际收益率，`rm = (1+r)^(1/12) − 1`，`n` 为年数：

```
期末实际购买力 = P₀ × (1+r)ⁿ
               + 月投入 × [((1+r)ⁿ − 1) / rm] × (1 + rm)
               + 年投入 × [((1+r)ⁿ − 1) / r ] × (1 + r )

期末名义金额   = 期末实际购买力 × (1 + 通胀率)ⁿ
```

当 `|r| < 1e-12` 时退化为线性累加，避免除零。

## 默认参数的来源

| 参数 | 默认值 | 依据 |
|---|---|---|
| 年化收益率 | 10% | 标普 500 长期名义总回报的历史均值 |
| 年通胀率 | 3% | 美国长期通胀均值 |
| 实际收益率 | 6.80% | 由上两项换算得出 |

历史均值不是预测。当前估值水平下，多家机构对美股未来十年的实际回报预期在 3–5%。建议把收益率在区间内拉一遍看范围，而不是盯住单一数字。

## 模型的局限

- **确定性匀速增长**。真实市场不会这样走。同样的平均收益，涨跌顺序不同，在有持续投入的情况下终值差别很大（顺序风险）。
- **不含费用与税**。宽基指数 ETF 费率通常在 0.03% 量级，影响极小；应税账户的分红税和资本利得税则需要另行扣减。
- **不含行为因素**。模型假设你在任何市况下都不中断投入，这个假设往往比收益率假设更脆弱。

## 本地运行

直接用浏览器打开 `index.html` 即可，但 Service Worker 只在 `https` 或 `localhost` 下注册，所以本地双击打开时离线功能不生效。要完整测试：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 文件结构

```
index.html             单文件应用，样式与脚本全部内联
sw.js                  Service Worker，页面走网络优先、断网回落缓存
manifest.webmanifest   PWA 清单
icon-192.png           应用图标
icon-512.png           应用图标
```

## 更新方法

改动 `index.html` 后直接提交即可。页面本身采用网络优先策略，联网状态下刷新就能拿到新版。若改动了 `sw.js` 缓存的资源清单，把 `sw.js` 里的 `CACHE` 版本号加一。
